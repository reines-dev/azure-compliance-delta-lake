
Las Claves API son credenciales de autenticación personal que puede crear, y luego pasar en el lugar de un nombre de usuario y contraseña, al utilizar la autenticación básica HTTP para realizar llamadas a la API. Las claves son propiedad de un solo usuario y tienen derechos, roles y permisos idénticos a ese usuario.

Recuerde que una vez creada, verá la clave secreta API solo una vez. Si extravía el secreto, deberá eliminar su clave y crear una nueva.
Por favor lea la sección «Authentication» del sitio de programador de Socrata para obtener información adicional.
https://dev.socrata.com/docs/authentication.html
